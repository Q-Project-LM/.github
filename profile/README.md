---

We pretrain language and agent models from scratch — our tokenizer, our data, our weights.
Some we open for anyone to run; some we keep private.

### Open models
- **Q-50M-Base** — 50.9M-parameter decoder-only language model, pretrained on 5B tokens of
  FineWeb-Edu. GQA + QK-Norm, 32k BPE vocab, 2,048 context. Apache 2.0 — small enough to run
  on a laptop.

### In training
- A larger model built for perception and for acting through tools, not only predicting text.
  Details stay under wraps until release.

### What we work on
| | |
|---|---|
| **Pretrain** | Foundations from the first token — our own tokenizers, data mixes, and stable, efficient architectures. |
| **Finetune** | Base models become capable and well-behaved through supervised and preference tuning. |
| **Agents**   | Models that perceive, use tools, and carry multi-step work to a reliable finish. |
| **Research** | We publish what we learn — models, datasets, and notes on small models that punch above their size. |
